# 🚀 HaproShow

**HaproShow** is a project showcase platform by **Haproven** where developers, students, and creators can showcase, discover, and share their projects.

> **Show your project. Share your ideas. Get discovered.**

---

## ✨ About HaproShow

HaproShow is built to give projects a dedicated space on the web.

Creators can present their projects with important details such as:

* 📌 Project name and description
* 👤 Project creator
* 🛠️ Technologies used
* 🖼️ Project screenshots
* 🔗 Live demo
* 💻 Source code / GitHub repository
* 🏷️ Project category
* 📅 Project information

The goal is to make it easier for people to **discover projects, explore ideas, and connect with creators**.

## 🛠️ Features

### Project Showcase

Present projects with a clean and structured project page.

### Creator Profiles

Connect projects with their creators through HaproID.

### Project Discovery

Browse and discover projects created by members of the community.

### Live Demo

Provide a direct link to try the project.

### Source Code

Link projects to their GitHub repositories.

### Categories & Technologies

Organize projects by category and technology.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/haproven/haproShow.git
```

Go to the project directory:

```bash
cd haproShow
```

Then open the project in your preferred code editor and run it using your local development environment.
